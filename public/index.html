快速开始
1

配置 AI 客户端

复制以下配置，发给你的 AI 助手让它帮你配，或手动添加到 MCP 配置文件中：

{
  "mcpServers": {
    "AISkillBox": {
      "url": "http://127.0.0.1:10881/mcp"
    }
  }
}

配置文件位置因客户端而异，AI 助手会自动识别。

2

开始使用

重启 AI 客户端，直接对话即可管理 Skill：

  • "列出所有 skill"
  • "搜索跟你技能相关的内容"
  • "禁用 xxx skill"

常见问题

Q: 服务未运行 / 双击没反应

检查端口是否被占用（见下方）。确认 AISkillBox-mcp.exe 和 AISkillBox.exe 在同一目录。以管理员身份尝试启动。

Q: 启动失败 / 闪退

可能是 skills.db 损坏，删除后重启会自动重建。也可能是 config.toml 格式错误，检查后修正。

Q: 端口占用 (10881 / 10882)

运行 netstat -ano | findstr 10881 查找占用进程，taskkill /PID <pid> /F 终止。或修改 config.toml 中的端口号。

Q: AI 客户端连不上 MCP 服务

确认 AISkillBox-mcp.exe 正在运行。确认配置的端口（默认 10881）和地址（http://127.0.0.1:10881/mcp）正确。重启 AI 客户端。

Q: Skill 没有出现在列表中

确保 Skill 放在 skills/ 目录下，且包含 SKILL.md 文件（需有 YAML front matter）。点击"刷新"或调用 refresh_skills。

Q: 删除的 Skill 如何恢复

通过 Web 后台"回收站"页面恢复，或调用 restore_skill 工具。永久删除需在回收站中操作。
